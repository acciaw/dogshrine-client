Undertale — save editor

Loading a slot replaces your live save with the slot's. Your current save is always backed up first — but close the game before loading.

This game uses Steam Cloud — Steam can resync your old save right over a slot you just loaded. Turn off Cloud saves for it (Steam → right-click the game → Properties → General) if you're going to rely on slots.

    These are the splits available for this game in the overlay's LiveSplit widget — switch between them from the overlay's over-focus panel while playing. PB, best segments and attempts are kept per splits file and persist across restarts.

      Settings

      Personalization
      Theme

      Pick a look inspired by a location from Undertale or Deltarune.

      Updates

      Checks GitHub for a newer release when Dog Shrine starts, and, if one's found, downloads it and restarts into it automatically before the app window opens. Your saves, slots, backups, and settings live outside the app's install folder and are never touched by an update. Turn this off to update manually instead, from the button below.

      Sound

      Sounds are used for things such as [[HYPERLINK BLOCKED]] — turn this off if you'd rather Dog Shrine stayed silent.

      Overlay

      Shows a speedrunner overlay on top of a running game — a LiveSplit timer and a live keystroke display. Turn this off to disable every overlay feature and its hotkeys below.

      Widgets

      Splits

      Splits are managed from the in-game overlay: while a game is running, press your over-focus hotkey (F8 by default) to load a .lss, switch between saved splits, and export. Splits and their PB / best segments are saved per game and kept across restarts.
