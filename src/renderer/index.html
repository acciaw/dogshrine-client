Undertale — save editor

Loading a slot replaces your live save with the slot's. Your current save is always backed up first — but close the game before loading.

This game uses Steam Cloud — Steam can resync your old save right over a slot you just loaded. Turn off Cloud saves for it (Steam → right-click the game → Properties → General) if you're going to rely on slots.

    Theme

    Pick a look inspired by a location from Undertale or Deltarune.

    Updates

    Checks GitHub for a newer release when Dog Shrine starts, and, if one's found, downloads it and restarts into it automatically before the app window opens. Your saves, slots, backups, and settings live outside the app's install folder and are never touched by an update. Turn this off to update manually instead, from the button below.
